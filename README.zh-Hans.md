## macOS 应用

### [DeepSeek Harness for macOS](https://github.com/qingtan-labs/deepseek-harness-macos)

一款面向 DeepSeek Harness（DSH）的原生 macOS Dock 与菜单栏控制器。它可以管理本地 DSH 服务，优先复用已有的 Harness 浏览器标签页，并支持使用可选的应用内窗口。

- **主要功能：** Dock 与菜单栏入口、浏览器标签页复用、服务健康状态与启停控制、登录时启动、英文与简体中文界面，以及同时支持 Apple 芯片和 Intel Mac 的通用版本
- **系统要求：** macOS 13 Ventura 或更高版本
- **开源许可：** MIT
- **相关链接：** [源代码](https://github.com/qingtan-labs/deepseek-harness-macos) · [下载最新版](https://github.com/qingtan-labs/deepseek-harness-macos/releases/latest) · [English](https://github.com/qingtan-labs/deepseek-harness-macos/blob/main/README.md)
