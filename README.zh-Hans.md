## macOS 应用

### [DeepSeek Harness for macOS](https://github.com/qingtan-labs/deepseek-harness-macos)

一款面向 DeepSeek Harness（DSH）的原生 macOS Dock 与菜单栏控制器。它可以管理本地 DSH 服务，优先复用已有的 Harness 浏览器标签页，并支持使用可选的应用内窗口。

- **主要功能：** Dock 与菜单栏入口、浏览器标签页复用、服务健康状态与启停控制、登录时启动、英文与简体中文界面，以及同时支持 Apple 芯片和 Intel Mac 的通用版本
- **系统要求：** macOS 13 Ventura 或更高版本
- **开源许可：** MIT
- **相关链接：** [源代码](https://github.com/qingtan-labs/deepseek-harness-macos) · [下载最新版](https://github.com/qingtan-labs/deepseek-harness-macos/releases/latest) · [English](https://github.com/qingtan-labs/deepseek-harness-macos/blob/main/README.md)

### [StatusPerch](https://github.com/qingtan-labs/StatusPerch)

一款轻量、原生的 macOS 菜单栏收纳工具。将低频状态图标放到可移动边界的左侧，即可通过箭头一键收起或展开。

- **主要功能：** 一键收起与展开、按住 Command 拖动调整位置、定时自动收起、登录时启动、英文与简体中文、完全本地运行，以及同时支持 Apple 芯片和 Intel Mac 的通用版本
- **系统要求：** macOS 13 Ventura 或更高版本
- **授权方式：** 专有免费软件
- **相关链接：** [项目仓库](https://github.com/qingtan-labs/StatusPerch) · [下载最新版](https://github.com/qingtan-labs/StatusPerch/releases/latest) · [English manual](https://github.com/qingtan-labs/StatusPerch/blob/main/docs/user-manual/en/README.md) · [简体中文手册](https://github.com/qingtan-labs/StatusPerch/blob/main/docs/user-manual/zh-Hans/README.md)
